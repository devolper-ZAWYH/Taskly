# Icons (generated — see prerequisites)

Tauri requires raster icons; the repo currently ships only the vector brand
icon `C:\Users\...\Desktop\Taskly\public\brand\taskly.svg` (copied to
`source/taskly.svg` next to this note).

## What goes where

- `source/taskly.svg` — brand vector (read-only reference copy).
- `source/app-icon-1024.png` — placeholder 1024x1024 RGBA PNG generated by
  `scripts/make_placeholder_icon.py` so icon generation can run *today*.
- Top-level generated files (32x32.png, 128x128.png, 128x128@2x.png,
  icon.ico, icon.icns, Square*.png …) are regenerated from the source and are
  deliberately git-ignored (`desktop-app/.gitignore`).

## Needed files & how they are produced

`turi icon` generates everything from ONE square, transparent 1024x1024
PNG (RGBA). Generated set (into this folder):

- 32x32.png, 128x128.png, 128x128@2x.png, icon.png — window/BMP icons
- icon.ico — Windows executable + NSIS installer icon (256px embedded)
- icon.icns — macOS (needed later for the macOS phase)
- Square*.png (30/44/71/89/107/142/150/310), StoreLogo.png — Windows
  Store/MSIX assets
- 128x96.png / Scale-200.png etc. (Windows app assets)

## Commands (run from `desktop-app/`)

```powershell
# Placeholder already generated once via the stdlib script (no deps needed):
python scripts\make_placeholder_icon.py

# Generate the runtime icon set (creates this folder's made files):
cargo tauri icon src-tauri\icons\source\app-icon-1024.png
```
